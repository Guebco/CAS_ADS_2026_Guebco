Course materials
================

Module 1 — Data management and acquisition
------------------------------------------

The `Module 1 notebooks
<https://github.com/Guebco/CAS_ADS_2026_Guebco/tree/main/Module%201/notebooks>`_
cover data management, visualization, APIs, and MySQL. The
`database materials
<https://github.com/Guebco/CAS_ADS_2026_Guebco/tree/main/Module%201/M1-D2-DB>`_
include SQL exercises, an SQLite database, and a Python query example.
The ``M1-D2-Webscraping`` directory contains lectures, exercises, and solutions.

Module 2 — Statistics
---------------------

`Module 2
<https://github.com/Guebco/CAS_ADS_2026_Guebco/tree/main/Module%202>`_
covers descriptive statistics, probability, regression, and hypothesis testing.
Start with ``CAS-D2-Regression.ipynb`` for an example that uses the included
``iris.csv``. The Mann–Whitney U test example lives in its own subdirectory with
a teaching dataset.

Module 3 — Machine learning
---------------------------

`Module 3
<https://github.com/Guebco/CAS_ADS_2026_Guebco/tree/main/Module%203>`_
covers linear models, trees and random forests, clustering, dimensionality
reduction, and neural networks. The numbered notebooks are organized by topic.
The module has its own Python compatibility range and dependency lockfile.

Module 4 — Software development practices
-----------------------------------------

`Module 4
<https://github.com/Guebco/CAS_ADS_2026_Guebco/tree/main/Module%204>`_
contains material on GitHub, development practices, IT security, and legal and
neuroscience topics. The ``CAS_ADS_4-main`` directory holds examples for pytest,
large files, and documentation. See :doc:`analytics-api` for the documentation
example's classes and functions.

Projects and experiments
------------------------

* ``1_Project_Submissions/`` contains the concept report, football survey
  analysis, and a project on predicting exit intentions.
* ``Example_Datasets_Playground/`` contains notebooks exploring OULAD and UTAUT
  datasets.
* ``Sandbox/`` contains pandas and visualization experiments.
* ``Module 5/``, ``Module 6/``, and ``Final Project/`` currently contain
  placeholder READMEs.
