Analytics example API
=====================

The Module 4 analytics example uses only the Python standard library. It
demonstrates typed interfaces and Google-style docstrings. Run the demo from
the repository root.

.. code-block:: bash

   python "Module 4/CAS_ADS_4-main/documentation/analytics.py"
