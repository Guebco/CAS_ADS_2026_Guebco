CAS Applied Data Science 2026
=============================

This repository collects Cornel Guebeli's coursework for the CAS in Applied
Data Science. It contains lecture materials, worked examples, notebooks, and
project submissions.

Start with the course material index to find a topic, then use the setup guide
to choose an environment and run the examples.
